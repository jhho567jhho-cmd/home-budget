# Home Budget Manager

מערכת מקיפה לניהול תקציב בית - עוקבת אחרי הכנסות, הוצאות, תקציבים וקטגוריות.

## תכונות
- 📊 ניהול תקציבים חודשיים לפי קטגוריה
- 💰 עקיבות הוצאות והכנסות
- 📈 דוחות וניתוח כלכלי
- 🏷️ ארגון לפי קטגוריות מותאמות
- 💾 שמירה מקומית של הנתונים

## הפעלה

```bash
npm install
npm start
```

הפתח את `http://localhost:3000` בדפדפן.

## מבנה הפרויקט
- `/src` - קוד ה-React
- `/public` - קבצים סטטיים
- `/src/data` - ניהול הנתונים המקומיים
